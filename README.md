# Проект "Банковские операции"

## Описание проекта

Проект предназначен для обработки и анализа данных о банковских транзакциях. Он предоставляет удобные функции для фильтрации и сортировки операций по различным критериям, а также для маскировки конфиденциальных данных (номеров карт и счетов).

## Цель проекта

Разработать набор инструментов для работы со списком банковских операций, позволяющий:
- Фильтровать операции по их статусу (EXECUTED, CANCELED и т.д.)
- Сортировать операции по дате выполнения
- Маскировать номера карт и счетов для безопасного отображения

## Технологии

- Python 3.7+
- Git
- Flake8 (проверка стиля кода)
- MyPy (проверка типов)
