# Проект "Банковские операции"

## Описание проекта

Проект "Банковские операции" предназначен для обработки и анализа данных о банковских транзакциях. Он предоставляет удобные функции для фильтрации и сортировки операций по различным критериям.

## Цель проекта

Разработать набор инструментов для работы со списком банковских операций, позволяющий:
- Фильтровать операции по их статусу (EXECUTED, CANCELED и т.д.)
- Сортировать операции по дате выполнения

## Требования к окружению

- Python 3.7 или выше
- Git (для клонирования репозитория)
